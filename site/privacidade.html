Privacidade

Privacidade sem complicações.

Explicamos o que fica no seu dispositivo, o que não pedimos e como funcionam as ferramentas públicas do Guia.

Guia Migrante PT Verificado em 20/08/2026 Portal independente
Resumo simples

O Guia foi desenhado para funcionar sem conta.

Na versão atual, não é necessário criar perfil, iniciar sessão ou enviar cópias de documentos ao Guia Migrante PT para consultar a informação e usar as ferramentas públicas.

As checklists, preferências de acessibilidade e algumas datas que decide guardar ficam no armazenamento local do próprio browser/dispositivo. Não são enviadas pelo Guia para uma base de dados própria de utilizadores.
1. Dados que o Guia não pede

Não envie documentos sensíveis através do portal.

  • Passaporte, título de residência ou cartão de cidadão.
  • Passwords, PINs, códigos de autenticação ou Chave Móvel Digital.
  • Dados bancários completos ou fotografias de cartões.
  • Registos médicos ou outros documentos pessoais sensíveis.

As ferramentas foram concebidas para orientação e organização, sem necessidade de carregamento desses ficheiros.

2. Armazenamento local

O que pode ficar guardado no seu dispositivo

Algumas funcionalidades usam mecanismos do browser, como localStorage, para recordar progresso de checklist, preferências visuais ou uma data que tenha escolhido guardar.

Pode apagar esses dados através da própria área de Ferramentas ou limpando os dados do site no seu navegador.

Abrir Ferramentas →
3. Cache e versão instalável

Funcionamento como PWA

O site pode usar o armazenamento de cache do navegador para permitir carregamentos mais rápidos e acesso a algumas páginas com ligação fraca. Este mecanismo guarda ficheiros públicos do próprio site, não um perfil pessoal.

4. Dados técnicos de alojamento

O serviço de alojamento pode processar dados técnicos

Como em qualquer site, o fornecedor de alojamento e rede pode processar informação técnica necessária para entregar a página, proteger o serviço e detetar abuso, como endereço IP, hora do pedido, tipo de navegador ou dados semelhantes.

O Guia não utiliza atualmente esses dados para criar perfis pessoais de utilizadores nem para vender informação a anunciantes.

5. Links externos

Sites oficiais e serviços de terceiros

Quando abre um link para AIMA, gov.pt, Justiça, Segurança Social, SNS ou outra entidade, passa a aplicar-se a política de privacidade desse website externo. O Guia Migrante PT não controla o tratamento de dados feito por esses serviços.

6. Cookies

Sem cookies publicitários nesta versão

O portal atual não precisa de cookies de publicidade nem de uma conta pessoal para disponibilizar as funcionalidades descritas. Se no futuro forem adicionados serviços que alterem esta situação, esta política deverá ser atualizada antes dessa utilização.

7. Alterações

Esta política pode ser atualizada

Se forem introduzidas novas funcionalidades — por exemplo, formulários, analytics, notificações ou serviços com tratamento adicional de dados — a política será revista para explicar de forma clara o que mudou.
